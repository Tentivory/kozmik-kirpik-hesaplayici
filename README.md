# 🌌 KOZMİK KİRPİK HESAPLAYICI 🌌

## DÜNYANIN EN ÖNEMLİ BİLİMSEL KEŞFİ

Bu repository, insanlık tarihinin en kritik sorusuna cevap verir:

**"Bugün tam olarak kaç kere göz kırpmalıyım?"**

Evet. Bu soru. Artık cevap var.

### NEDEN BU PROJE VAR?

Çünkü:
- Göz kırpmak rastgele olmamalıdır.
- Evren size kaç kere kırpmamız gerektiğini fısıldar.
- Biz de o fısıltıyı Python ile duyduk.
- Ve siz de duymalısınız.

### NASIL ÇALIŞIR?

1. Programı çalıştır.
2. Adını gir.
3. Evrenle bağlantı kurulur.
4. Sana özel, kişiselleştirilmiş, bilimsel (değil) bir sayı alırsın.
5. O sayı kadar göz kırp.
6. Dünya kurtulur.

### KURULUM

```bash
python kirpik_hesapla.py
```

Başka hiçbir şey gerekmez. Kütüphane yok. Bağımlılık yok. Sadece sen ve kozmos.

### BİLİMSEL TEMEL

- 42 sayısı kullanılır çünkü her şeyin cevabıdır.
- Rastgele sayılar aslında rastgele değildir, evrenin kararıdır.
- Zaman damgası mod 777 alınır çünkü 777 şanslıdır (ve biz de öyleyiz).
